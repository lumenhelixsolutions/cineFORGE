Install in seconds

Install cineFORGE locally with a Python virtual environment, the SolidJS UI, and Tauri dev tooling.

python3.12 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install -e ".[vertex,fal,dev]"
cd ui && npm install
cd .. && cargo tauri dev

How it works

A three-tier pipeline: Python backend, SolidJS UI, Rust Tauri shell.

cineFORGE/
├── backend/     Python 3.12 + FastAPI — adapters, director, stitcher
├── ui/          SolidJS + Tailwind — project editor and timeline
└── src-tauri/   Tauri 2.x (Rust) — desktop shell and system bridge
